# Usecase Writer Examples

This directory contains anonymized example usecase scripts for reference.

## Files

### Dairy Brand Rejuvenation Case Study

  - Minimal product UI touchpoints (input + report only)

## Anonymization

All brand names, locations, and identifying information have been anonymized to protect client confidentiality:

- **Brand names** → "Brand A", "A leading dairy brand"
- **Geographic locations** → "City A", "City B"
- **Platform names** → "a popular social platform"
- **Competitive benchmarks** → Retained (Heinz, Nike, Coca-Cola) as they are public reference cases

## Use Cases

These examples demonstrate three core usecase templates:

1. **Template A: Market Validation** - Testing new product concepts with target audiences
2. **Template B: Reusable Panel** - Re-engaging past research participants for new insights
3. **Template C: Comparative Validation** - Verifying traditional research methods with Atypica

## Quality Standards

Both examples meet the quality criteria defined in the usecase-writer skills:

- ✅ Specific hook questions that grab attention
- ✅ Clear traditional method limitations (2+ dimensions)
- ✅ Strong transition to introduce Atypica
- ✅ Transparent research process with concrete details
- ✅ Layered findings presentation (First, Second, Third)
- ✅ Actionable solution section (to-do next)
- ✅ Elevated CTA with memorable phrasing
- ✅ Product UI touchpoints to build credibility

## How to Use

1. Read both versions to understand the difference between short and long formats
2. Identify which template (A, B, or C) best fits your use case
3. Follow the structure and quality checklist from the relevant skill
4. Adapt the anonymized example to your specific case study
5. Run quality checks before finalizing
